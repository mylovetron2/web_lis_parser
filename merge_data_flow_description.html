Mô tả luồng dữ liệu khi merge trong LIS Parser

1. Mục tiêu

Đảm bảo dữ liệu từ file TXT (DEPTH) được hợp nhất chính xác vào dữ liệu LIS, loại bỏ các dòng không hợp lệ và chuẩn hóa dữ liệu TIME/DEPTH.

2. Luồng dữ liệu tổng quát

  1. Đọc dữ liệu LIS → getTableData đọc file LIS, chuyển TIME từ ms sang giây hoặc định dạng hh:mm:ss nếu cần.
  2. Đọc DEPTH từ TXT → Lấy danh sách DEPTH cần merge.
  3. Merge DEPTH vào tableData → mergeDepthToTable gán DEPTH từ TXT vào cột DEPTH của tableData, đồng thời loại bỏ các dòng TIME không hợp lệ (TIME null hoặc không khớp).
  4. Chuẩn hóa dữ liệu → normalizeTableData sắp xếp, tính toán lại step, loại bỏ dòng trùng/không hợp lệ, đảm bảo TIME/DEPTH hợp lệ.
  5. Lưu hoặc xuất dữ liệu → Dữ liệu đã merge và chuẩn hóa được dùng để hiển thị, lưu file LIS mới hoặc tải về (web: tạo Blob, desktop: ghi file).

3. Chi tiết các bước chính

  • getTableData: Đọc file LIS, chuyển TIME từ ms sang giây hoặc hh:mm:ss để hiển thị.
  • mergeDepthToTable: Gán DEPTH từ TXT vào tableData, loại bỏ TIME null, đảm bảo chỉ giữ lại các dòng hợp lệ.
  • normalizeTableData: Sắp xếp lại dữ liệu, tính step (có thể âm nếu dữ liệu giảm dần), loại bỏ dòng trùng hoặc TIME/DEPTH không hợp lệ.

4. Lưu ý về TIME và stepChuanHoa

  • TIME được chuyển từ ms sang giây hoặc hh:mm:ss để dễ đọc.
  • stepChuanHoa có thể âm nếu dữ liệu DEPTH giảm dần (đi lên), dương nếu tăng dần (đi xuống).
  • Các dòng có TIME null hoặc DEPTH không hợp lệ sẽ bị loại bỏ trong quá trình merge/normalize.

5. Sơ đồ luồng dữ liệu

TXT DEPTH  ──┐
            │
            ▼
      [mergeDepthToTable]
            │
            ▼
      [normalizeTableData]
            │
            ▼
      [tableData đã chuẩn hóa]
            │
            ├──> Hiển thị UI
            └──> Lưu/Tải file LIS mới

6. Tham khảo code chính

  • lib/services/lis_file_parser.dart: mergeDepthToTable, normalizeTableData, getTableData
  • lib/widgets/data_table_widget.dart: UI, trigger merge/download
