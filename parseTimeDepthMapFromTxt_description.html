Mô tả hàm parseTimeDepthMapFromTxt

Chức năng

Hàm parseTimeDepthMapFromTxt dùng để đọc nội dung file TXT chứa dữ liệu đo, trích xuất cột TIME và DEPTH (hoặc DEPT), và trả về một Map<String, String> ánh xạ TIME (giây) sang DEPTH.

Tham số

  • txtContent: Nội dung file TXT dạng chuỗi, mỗi dòng là một bản ghi, có header.

Giá trị trả về

  • Map<String, String>: key là TIME (đã chuyển sang giây, dạng chuỗi), value là DEPTH.
  • Trả về null nếu không tìm thấy header hợp lệ hoặc dữ liệu không đủ.

Logic chính

  1. Tìm dòng header chứa các cột TIME, DEPTH/DEPT và (nếu có) LSPD.
  2. Xác định chỉ số (index) của từng cột:
    • TIME: timeIdx
    • DEPTH/DEPT: depthIdx
    • LSPD (nếu có): lspdIdx
  3. Duyệt từng dòng dữ liệu, chuyển TIME về giây, ánh xạ TIME → DEPTH vào Map.
  4. Bỏ qua dòng không hợp lệ hoặc thiếu dữ liệu.

Ví dụ

TIME   DEPTH
35101  1000
35102  1001
// Kết quả:
{"35101": "1000", "35102": "1001"}
