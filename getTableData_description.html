📊 Mô tả hàm getTableData

File: lib/services/lis_file_parser.dart

Mục đích: Đọc và chuyển đổi dữ liệu từ Data Records trong file LIS thành dạng bảng để hiển thị trên UI

1. Chữ ký hàm (Function Signature)

Future<List<Map<String, dynamic>>> getTableData({int maxRows = 1000}) async

Tham số:

Tên Kiểu Mặc định Mô tả
maxRows int 1000 Số dòng tối đa cần đọc để tránh load quá nhiều dữ liệu

Giá trị trả về:

List<Map<String, dynamic>> - Danh sách các dòng dữ liệu

  • Key: Tên cột (mnemonic) như "DEPTH", "GR", "CALI"...
  • Value: Giá trị dữ liệu (String cho single values, Map cho arrays)

2. Quy trình xử lý (Processing Flow)

1 Kiểm tra điều kiện
  • File đã mở chưa? (isFileOpen)
  • Có Data Records không? (startDataRec, endDataRec)
  • Có Datum Blocks không? (datumBlocks.isEmpty)
Nếu không đủ điều kiện → Tạo dữ liệu mẫu (sample data) để test
2 Duyệt qua các Data Records 
for (recordIdx = startDataRec; recordIdx <= endDataRec; recordIdx++)
  • Bắt đầu từ record đầu tiên có data
  • Kết thúc ở record cuối cùng
  • Dừng sớm nếu đủ maxRows
3 Lấy dữ liệu frame
  • frameData = await getAllData(recordIdx) - Lấy toàn bộ data của record
  • frameNum = getFrameNum(recordIdx) - Số frame trong record
  • startingDepth = currentDepth - Độ sâu khởi đầu
4 Xử lý từng frame

Với mỗi frame trong record:

  • Tính độ sâu của frame
  • Trích xuất giá trị các curve
  • Tạo một dòng dữ liệu (row)

3. Tính toán độ sâu (Depth Calculation)

Công thức tính depth cho mỗi frame: double frameDepth = startingDepth; if (entryBlock.nDirection == LisConstants.dirDown) { // Khoan xuống: depth tăng frameDepth += frame * (step / 1000.0); } else { // Khoan lên: depth giảm frameDepth -= frame * (step / 1000.0); } row['DEPTH'] = frameDepth.toStringAsFixed(3);

Giải thích:

  • startingDepth: Độ sâu tại frame đầu tiên của record
  • frame: Index của frame (0, 1, 2...)
  • step: Khoảng cách giữa các frame (từ entryBlock)
  • step / 1000.0: Chuyển đổi từ mm sang m (nếu cần)

4. Xác định cấu trúc dữ liệu frame

Mỗi frame chứa dữ liệu của tất cả curves. Cần tính toán vị trí chính xác của từng giá trị:

Bước 1: Đếm số values trong 1 frame int singleValuesPerFrame = 0; // Số curve đơn int arrayElementsPerFrame = 0; // Tổng số phần tử array for (var datum in datumBlocks) { // Skip DEPT trong depth-per-frame mode if (entryBlock.nDepthRecordingMode == 0 && datum.mnemonic == 'DEPT') { continue; } if (datum.size <= 4) { singleValuesPerFrame += 1; // Single value } else { arrayElementsPerFrame += datum.dataItemNum; // Array elements } } int totalValuesPerFrame = singleValuesPerFrame + arrayElementsPerFrame;
Bước 2: Tính vị trí bắt đầu của frame int frameDataStartIndex = frame * totalValuesPerFrame; int currentIndex = frameDataStartIndex;
Ví dụ: Nếu mỗi frame có 5 single curves + 1 array curve (100 elements):
  • totalValuesPerFrame = 5 + 100 = 105
  • Frame 0 bắt đầu tại index: 0
  • Frame 1 bắt đầu tại index: 105
  • Frame 2 bắt đầu tại index: 210

5. Map dữ liệu vào các cột

5.1. Single Value Curves (size ≤ 4 bytes)

if (datum.size <= 4) {
    if (currentIndex < frameData.length) {
        final value = frameData[currentIndex];
        row[columnName] = value.isNaN ? 'NULL' : value.toStringAsFixed(3);
        currentIndex += 1;
    } else {
        row[columnName] = 'NULL';
    }
}

Xử lý:

  • Lấy giá trị tại currentIndex
  • Kiểm tra NaN → Hiển thị "NULL"
  • Format số với 3 chữ số thập phân: .toStringAsFixed(3)
  • Tăng index lên 1

5.2. Array Curves (size > 4 bytes)

else {
    // Array datum - hiển thị "..." và lưu metadata
    row[columnName] = {
        'display': '...',
        'isArray': true,
        'recordIdx': recordIdx,
        'frameIdx': frame,
        'datumName': columnName,
    };
    currentIndex += datum.dataItemNum;  // Skip array elements
}

Xử lý:

  • Không hiển thị giá trị chi tiết (quá nhiều data)
  • Hiển thị "..." trên UI
  • Lưu metadata để xem waveform khi user click
  • Skip qua tất cả elements của array
Array curves thường là waveform data (hàng trăm/nghìn điểm), không phù hợp hiển thị trong table cell

6. Thêm cột Adr (Address)

row['Adr'] = '$recordIdx:$frame';

Mục đích:

  • Lưu vị trí chính xác của frame trong file LIS
  • Format: recordIndex:frameIndex
  • Dùng để reference khi cần update/export dữ liệu
Ví dụ:
  • "10:0" - Frame đầu tiên của record thứ 10
  • "10:5" - Frame thứ 6 của record thứ 10
  • "25:12" - Frame thứ 13 của record thứ 25

8. Đặc điểm quan trọng

8.1. Skip DEPT trong depth-per-frame mode

if (entryBlock.nDepthRecordingMode == 0 && datum.mnemonic == 'DEPT') {
    continue;  // Skip DEPT column
}
  • Lý do: Trong mode này, depth được tính tự động cho mỗi frame
  • Không cần đọc giá trị DEPT từ data
  • Tránh duplicate cột DEPTH

8.2. Định dạng số (Number Formatting)

  • Tất cả số được format với 3 chữ số thập phân: .toStringAsFixed(3)
  • NaN values → Hiển thị "NULL"
  • Giữ dữ liệu dạng String để dễ hiển thị trên UI

8.3. Error Handling

  • Nếu currentIndex >= frameData.length → Return "NULL"
  • Nếu không đọc được data → Row bị skip
  • Try-catch bao quanh toàn bộ process

8.4. Performance Optimization

  • Giới hạn số rows (maxRows) để tránh lag UI
  • Không load toàn bộ file vào memory
  • Chỉ parse dữ liệu cần thiết

9. Sử dụng trong hệ thống

9.1. Từ DataTableWidget

final tableData = await parser.getTableData(maxRows: 1000);
setState(() {
    this.tableData = tableData;
    columnNames = parser.getColumnNames();
});

9.2. Từ Export/Merge functions

// Lấy toàn bộ data để export
final allData = await parser.getTableData(maxRows: 999999);

// Merge với TXT data
final merged = parser.mergeDepthToTable(
    txtContent: txtContent,
    tableData: allData,
    columnNames: columnNames,
);

9.3. Từ Chart Screen

// Lấy data mẫu để vẽ chart
final chartData = await parser.getTableData(maxRows: 500);
