Mô tả luồng dữ liệu khi nhấn nút Download file LIS

1. Mục tiêu

Khi người dùng nhấn nút Download, ứng dụng sẽ tạo file LIS mới từ dữ liệu đã chỉnh sửa (tableData) và trigger download file về máy (chỉ khả dụng trên web).

2. Luồng dữ liệu tổng quát

1. Người dùng nhấn nút Download (icon 💾)
   ↓
2. UI hiển thị dialog loading "Đang chuẩn bị file để download..."
   ↓
3. Tính toán startAdrSave (địa chỉ blank record đầu tiên trước data records)
   ↓
4. Gọi getModifiedFileBytes(tableData, columnNames, startAdrSave)
   ↓
5. getModifiedFileBytes xử lý:
   - Chuẩn hóa dữ liệu (normalizeTableData)
   - Đọc header file gốc (từ đầu đến startAdrSave)
   - Tính toán số frame/record, số record cần ghi
   - Ghi lại blank record và data record cho từng frame
   - Cập nhật EntryBlock (direction, frame spacing, depth)
   - Trả về Uint8List (toàn bộ file mới)
   ↓
6. Tạo tên file download (getDownloadFileName)
   ↓
7. Đóng dialog loading
   ↓
8. Nếu là web: gọi FileDownloadHelper.downloadFile(bytes, fileName)
   - Tạo Blob từ bytes
   - Tạo URL từ Blob
   - Tạo thẻ <a> và trigger click để download
   - Dọn dẹp URL
   ↓
9. Hiển thị thông báo thành công hoặc lỗi

3. Chi tiết các bước chính

  1. Tính startAdrSave:
    • Lấy địa chỉ của record đầu tiên trong lisRecords[startDataRec]
    • Trừ 16 byte để về blank record header
    • Giá trị này dùng để giữ nguyên phần header file gốc
  2. getModifiedFileBytes:
    • Chuẩn hóa tableData (sắp xếp, tính step, regression DEPT)
    • Đọc toàn bộ file gốc, lấy phần header (0 → startAdrSave)
    • Tính toán framePerRecordNew và numRec dựa trên tableData.length
    • Ghi lại từng blank record và data record theo cấu trúc LIS
    • Cập nhật EntryBlock với direction/step mới
    • Trả về Uint8List chứa toàn bộ file LIS mới
  3. FileDownloadHelper.downloadFile:
    • Tạo Blob từ Uint8List
    • Tạo object URL từ Blob
    • Tạo thẻ <a> với href=URL và download=fileName
    • Trigger click() để download file
    • Revoke URL để giải phóng bộ nhớ

4. Lưu ý quan trọng

  • Download chỉ khả dụng trên web browser, không hỗ trợ desktop.
  • File mới được tạo hoàn toàn từ tableData, không phải chỉnh sửa file gốc.
  • Các thay đổi (edit cell, merge DEPTH/SPEE) đều được áp dụng vào file mới.
  • EntryBlock được cập nhật lại direction và step dựa trên dữ liệu đã chuẩn hóa.

5. Sơ đồ luồng dữ liệu

tableData (đã edit/merge)
    │
    ↓
[Chuẩn hóa: sort, step, regression]
    │
    ↓
[Đọc header file gốc (0 → startAdrSave)]
    │
    ↓
[Tính framePerRecordNew, numRec]
    │
    ↓
[Ghi blank record + data record cho từng frame]
    │
    ↓
[Cập nhật EntryBlock]
    │
    ↓
[Uint8List: file LIS mới hoàn chỉnh]
    │
    ↓
[Tạo Blob → URL → trigger download]
    │
    ↓
File LIS mới được tải về máy
